# Рилсы: как строим сценарий

Рилс — вертикальное видео 1080×1920, 10–16 секунд, рисуется в панели из сцен (`posts.reel`). Видео записывается в браузере (MP4), операции Make не тратятся.

## Логика
Сначала одна мысль рилса одной фразой (`reel.idea`). Каждая сцена — шаг этой мысли: зацепить → показать → объяснить → вердикт → в канал. Факты, цифры и имена — только из поста.

## Схемы по рубрикам
| Рубрика | Схема |
|---|---|
| Находка, Разбор, новость с фото | photo (главное фото на весь экран + крючок) → photo (факт/деталь) → photo карточкой (приём) → text (вердикт) → end |
| Крафт | title (крючок) → ui (экраны с приёмом именно этого поста) → text (правило) → end |
| Мысль | 2–3 × text → end |

## Сцены
- `photo`: `src` (ссылка на фото поста или загруженное в панель), `title`, `sub`, `credit`, `layout` full/card, `zoom` in/out/none, `fx`/`fy` — кадрирование, `hl` — выделить последнюю строку.
- `title`, `text`, `end`: `title` (строки через перенос), `sub`, `hl`.
- `ui`: до 3 экранов `{tag, head, kind: list|skeleton|progress, value, note, caption, capColor}`.
- У всех: `dur`, `bg` cream/ink/orange, `accent`, `size` S/M/L, `align`, `head`.

## Фото и запись
Панель не может показывать картинки с чужих сайтов. Поэтому, когда в рилсе есть фото по внешней ссылке, панель один раз переносит его в своё хранилище через сценарий Make 6848987 «Фото по ссылке в base64» (~3 операции на фото) и запоминает соответствие в `posts.photo_assets`. Если не получилось — кнопка «Своё фото».

Пример: `fd_20261031_luzhniki` — рилс на трёх фото студии.

## Поиск фото
Кнопка «✦ Claude найдёт фото» пишет `posts.photo_request` и запускает задачу «Поиск фото» (`docs/automation/photo-search.md`). Задача кладёт ссылки в `photo_urls` и описание каждого фото в `photo_meta` (`what`, `credit`, `text_on_photo`, `orientation`) — сценарист рилса учитывает их.

## Сцены 2.15 (в текущем стиле)
- `number`: `pre`, `value` (счётчик досчитывает от нуля), `title`, `hl`.
- `swatches`: `title`, `colors` (hex) или `from`/`to`/`count`, `pick`, `pickLabel`.
- `compare`: `title`, `a_label/a_text/a_color/a_src`, `b_…` — карточки как в «Интерфейсе».
- `list`: `title`, `items` (по строке), `mark` num/ok/no/mix — номера 01 02 03, как в каруселях.
Шрифты, переходы (плавное появление со сдвигом), шапка и финал — те же, что у остальных сцен. Попытка 2.14 (кинетический текст, маркер, знак «ДР» в финале) откачена: не попала в стиль канала.
