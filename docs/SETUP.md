# Развернуть редакцию с нуля

Порядок важен: сначала Telegram и Make (там живёт токен), потом панель, потом задачи. На всё — около часа.

## 0. Что нужно
- Аккаунт Claude (Pro или Max) с включёнными артефактами, задачами по расписанию и Claude Docs.
- Аккаунт [Make](https://www.make.com) (хватает платного тарифа с ~10 000 операций в месяц).
- Telegram: канал и бот от [@BotFather](https://t.me/BotFather).
- GitHub-аккаунт (для кода).

## 1. GitHub
1. Создай приватный репозиторий, например `designradar`.
2. Залей содержимое этого репозитория (или сделай форк, если репозиторий общий).
3. В claude.ai → Настройки → Коннекторы подключи **GitHub**. Чтобы Claude мог отправлять код, установи приложение Claude для GitHub: https://github.com/apps/claude/installations/select_target → свой аккаунт → «Only select repositories» → репозиторий.
4. Локальная сборка (по желанию):
   ```bash
   cd panel
   npm install
   npx playwright install chromium
   bash build.sh        # собирает dist/ и гоняет автопроверку
   ```

## 2. Telegram
1. @BotFather → `/newbot` → получи токен. **Токен никуда не вставляй, кроме Make.** Не присылай его в чат Claude.
2. Создай канал, добавь бота администратором с правом публиковать и редактировать сообщения.
3. Узнай id своего личного чата с ботом (напиши боту, затем `getUpdates` в Make) — он нужен для служебной загрузки фото (у нас 26530591).

## 3. Make
1. Создай подключение Telegram Bot с токеном (Connections).
2. Собери сценарии (каждый — «по запросу», с выходом Scenario outputs, чтобы Claude мог вызвать его как инструмент):
   - **DR util: telegram api** — входы `method` (text), `body` (text, JSON-строка). Модуль HTTP «Make a request» на `https://api.telegram.org/bot<токен из подключения>/{{method}}` с телом `{{body}}`, выход — ответ целиком. (Если используешь HTTP вместо модуля Telegram, храни токен в переменной/подключении, не в тексте модуля.)
   - **Обложка 2000×640** — входы `topic_id`, `title`, `label`, `art`, `image_base64`; проверяет размер, шлёт фото в служебный чат, удаляет сообщение, отдаёт `photo_file_id`.
   - **Загрузить фото для поста** — входы `image_base64`, `key`; то же без рендера.
   - **Фото по URL** — `image_url`, `topic_id` → `photo_file_id`.
3. В claude.ai подключи коннектор **Make**, включи нужные сценарии как инструменты и запиши их имена вида `s<ID>_<name>`.
4. В `panel/src/app/00-core.js` поправь константы: `CHANNEL`, `TOOL_TG`, `TOOL_COVER`, `SCN_PHOTO`.

## 4. Панель
1. Собери: `bash panel/build.sh` (должно быть «Все проверки прошли» и «BUILD OK»).
2. Попроси Claude опубликовать панель как артефакт из `panel/dist/`: `index.html` + файлы `styles.css`, `render.js`, `app.js`, с возможностями (capabilities):
   ```json
   {"db":{"rules":[ …см. DATA.md… ]},
    "user":{"scopes":["profile"]},
    "sample":{},
    "assets":{"upload":"interact"},
    "mcp":{"servers":[
      {"server":"Make","tools":["s6801242_dr_util_telegram_api","s6749993_design_radar_2000640","scenarios_run"]},
      {"server":"Claude Code Remote","tools":["fire_trigger","update_trigger"]}]}}
   ```
3. Открой панель, разреши ей доступ к Claude, Make и Claude Code Remote (спросит при первом использовании).
4. Запиши ссылку панели — она нужна в инструкциях всех задач.
5. Проверка: создай пост, «Опубликовать» в тестовый канал, затем «Исправить» и «Сохранить и обновить в канале».

## 5. Регламент
Создай в Claude Docs документ с разделами (образец — https://claude.ai/artifact/J3u5X8BL4ZHyQHzuB6HKzZ): «Стандарт канала», «Как пишем посты» с «Журналом ошибок» и **«Уроками из правок»**, «Самопроверка перед доставкой», «Инструкция для автопостов» (шаги, слоты, сетка недели, обложки и фото, справочник рисовальщика). Запиши id документа.

## 6. Задачи по расписанию
Создай задачи из [automation/](automation/) (попроси Claude: «создай задачу по инструкции из файла …»), подставив свои ссылку панели, id регламента, id сценариев и id задачи «Отложенная публикация» (её id прописан в панели — константа `DISPATCH` в `70-publish.js`; после создания задачи обнови константу и пересобери панель).

Минимальный набор, чтобы канал жил: «Запас постов», «Отложенная публикация», «Уроки из правок». Слоты и «Мысль» — по желанию.

## 7. Проверить всё вместе
- [ ] Пост создаётся, правится, публикуется и обновляется в канале.
- [ ] «Запланировать» на +15 минут — пост вышел сам.
- [ ] «+» → тема → «Отдать Claude» — через ≤ 1 часа пост в «Ревью».
- [ ] «Отклонить» → причина → вечером в регламенте появилось правило.
- [ ] Приглашение по ссылке → анкета → пост автора виден главреду, чужие посты автор править не может.
- [ ] На телефоне видна нижняя панель (подкрутить «Настроить вид» → «Подъём от нижнего края»).

## Безопасность
- Токен бота — только в Make. В репозиторий, панель, задачи и чат — никогда.
- Репозиторий приватный: в `panel/test/mockreal.js` копия настоящих постов.
- Панель открыта по ссылке. Удалённого редактора убирай ещё и в меню «Поделиться» артефакта.
