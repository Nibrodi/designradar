## Важные решения
- Подписку Claude нельзя давать другим людям через свой продукт; для публичного сервиса — только API-ключ, и Россия не входит в поддерживаемые регионы. Поэтому редакция — для одного канала; авторы работают через панель со своими аккаунтами Claude.
- В канал ничего не уходит без кнопки Екатерины (или доверенного автора с `can_publish`).
- Новые обложки не заменяют старые без её запроса.
- Операции Make до согласования не тратятся: ни обложки, ни фото не загружаются в Telegram, пока пост не одобрен.
