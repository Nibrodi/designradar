# Картинки для игр

Карточка 1080×1350 собирается как HTML и снимается в PNG: `CHROME_PATH=/usr/bin/google-chrome node games/render.js <абсолютный путь>.html out.png` (Playwright из panel/node_modules). Образец — `banks.html` (игра про банки в App Store, 07.11.2026).

Правила, чтобы картинка не выглядела нейросетевой:
- Сетка: поля 80 px; сверху лейбл «ИГРА», заголовок InterDisplay ExtraBold 80–84 px, подзаголовок Inter Medium 34 px; снизу футер (линия 2 px, @designradar_lab слева, «ответ в опросе ниже» справа, JetBrains Mono 22 px).
- Между содержимым и линией футера не меньше 56 px. render.js печатает `gap` — при меньшем зазоре ужимай содержимое, а не футер. Содержимому нужен id="store", футеру id="foot".
- Показывай настоящий интерфейс, в котором живёт вопрос (поиск App Store, корзина, клавиатура), а не набор картинок.
- Иконки — плоские, как настоящие иконки приложений: заливка во весь квадрат со скруглением 22,5 %, один простой знак, 2–3 цвета, без контуров, теней и мелких деталей. Никакого клипарта.
- Оранжевый — только акцент: лейбл, буквы вариантов, одна системная ссылка. Кнопки нейтральные.
- Шрифты локальные (Inter из /usr/share/fonts/opentype/inter, JetBrains Mono), проверить, что render.js показал все шрифты loaded.
