# Движок бота-редактора (Make 6750493)

С 29.10.2026 код редактора хранится в хранилище 178568, запись `engine_v5`. Код разбит на три поля: `chat_id` + `status` + `payload`, при сборке части склеиваются через `\n`. Модуль 5 сценария только загружает этот код и запускает его через `new Function`. Чтобы поменять логику, достаточно обновить поле записи (data-store-records_update): переотправлять большой blueprint не нужно. Модуль 16 (сохраняет ID отправленных сообщений) остаётся в blueprint: он запоминает `drafts_message_id` для purpose `drafts`.

Проверка после правки: запрос `{"action":"replace_article","run_id":"healthcheck","topic_id":"healthcheck","expected_version":0,"article":{}}` должен вернуть `stale_result_ignored`.

## Что умеет v5

- Жирный, курсив и ссылки из сообщения Telegram (entities) превращаются в `**…**`, `__…__` и `[текст](url)`.
- Если пост скопирован из бота целиком, повтор заголовка и подвал (источник, ссылка, хэштеги) убираются.
- Если отправленное сообщение с правкой отредактировать в Telegram, пост обновится, пока после правки ничего не менялось.
- На присланный файл бот отвечает подсказкой «пришли текст сообщением».

### Черновики

- /drafts есть в меню бота.
- В чате остаётся только один список: старый удаляется.
- Рядом с каждым черновиком есть кнопка 🗑.
- Черновики, чья тема уже вышла в канал, убираются из списка автоматически.
- Когда черновик открывают, список удаляется.
- Черновики можно открыть, даже пока бот ждёт новый пост.

### Журнал правок

- При правке поста через бот запоминаются `orig_title` и `orig_text` (что было до первой правки) и ставится флаг `owner_edited`.
- При публикации в `S.edit_log` (последние 12 записей) пишется, какие строки Екатерина убрала и какие добавила.
- Каждый вечер в 22:13 по Москве задача «Уроки из правок Екатерины» превращает журнал в правила в разделе документа «Уроки из правок Екатерины» (внутри «Как пишем посты»). Этот раздел читают все задачи, которые пишут посты.
