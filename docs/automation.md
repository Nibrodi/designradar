## Публикация постов редакторов — инструкция задачи (с 31.10.2026, панель 2.0.0)

1. Прочитать `roles` и `editors`. Публикуют только авторы с `can_publish: true` и статусом не `paused`/`removed`. Права — только из `roles`.
2. Для каждого: посты `byauthor/<uid>/posts` со статусом `scheduled`, у которых `scheduled_at` наступил и `author == uid`.
3. Перед отправкой — статус `publishing` (с проверкой версии документа).
4. Сообщение: готовый `outbox.body` от панели главреда, иначе собрать из `prep` (обложка через Make 6749993, картинки — только с готовыми file_id; без них пост ждёт, пока главред откроет панель).
5. Отправка: Make 6801242, `sendRichMessage`.
6. Итог: `published` с номером сообщения; ошибка до отправки — обратно в `scheduled` с `publish_error`; неясный ответ — `publish_unknown`, без повтора.

Общую ленту `posts` эта задача не трогает.
