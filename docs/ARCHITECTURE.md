# Как устроена редакция «Дизайн-Радара»

Канал: [@designradar_lab](https://t.me/designradar_lab). Главный редактор — Екатерина. Claude — оператор: пишет черновики по расписанию, рисует обложки, ведёт панель и код.

## Схема

```
           ┌──────────────────────────── Claude (claude.ai) ────────────────────────────┐
           │                                                                            │
 Екатерина │  Панель «Редакция Дизайн-Радара»  ◄──── база панели (db) ────►  Задачи по   │
 и авторы ─┼─► (артефакт, этот репозиторий)          posts, ideas, …         расписанию │
           │        │                                     ▲                  (Claude)   │
           │        │ кнопки Claude (sample)              │ ArtifactData                │
           │        ▼                                     │                             │
           │  Регламент (Claude Docs) ◄────────── читают все задачи                     │
           └────────┬───────────────────────────────────────────────────────────────────┘
                    │ коннектор Make (mcp)
                    ▼
           Make: сценарии-утилиты ──► Telegram Bot API ──► канал @designradar_lab
```

Токен Telegram-бота хранится **только в Make**. Ни панель, ни задачи Claude его не видят.

## Части

### 1. Панель — `panel/`
Одностраничное приложение, опубликованное как артефакт Claude: https://claude.ai/artifact/DZErVxEJgTWjoZGPGd4Vw9 (доступ — по ссылке).

- `panel/src/app/*.js` — логика по частям, склеиваются по порядку имён в `dist/app.js`:
  `00-core` (константы, состояние, `h()`), `10-format` (markdown → HTML Telegram), `20-covers` (обложки, правила текста для Claude, «Переписать»), `30-helpers` (линтер, переписывание фрагмента, варианты заголовка), `40-carousel`, `50-preview`, `60-data` (пути в базе, права, `savePost`, `adoptPost`), `70-publish` (публикация, отложенная, обновление в канале), `80-views` (лента, карточки, вкладки, идеи), `85-admin` (приглашения, роли), `87-editors` (анкета, тестовый вход), `90-editor` (редактор), `95-version` («Что нового»), `96-mobile` (мобильная шапка и меню), `97-newpost` (выбор темы «+»), `97a-design` («Настроить вид»), `97b-reject` (причина отказа), `99-boot` (запуск, подписки на базу).
- `panel/src/render.js` — рендер обложки 2000×640 со встроенным шрифтом (тот же код, что у Make-сценария обложки).
- `panel/src/styles.css`, `head.html`, `body.html`.
- `panel/VERSION`, `panel/CHANGELOG.md` — версия и история (3 последние записи видны в панели).
- `panel/build.sh` — сборка `dist/` + автопроверка `test/check.js` на копии базы (`test/mockreal.js`).

Возможности артефакта (capabilities): `db` с правилами доступа, `user` (profile), `sample` (кнопки Claude), `assets` (upload: interact), `mcp`: Make — `s6801242_dr_util_telegram_api`, `s6749993_design_radar_2000640`, `scenarios_run`; Claude Code Remote — `fire_trigger`, `update_trigger`.

### 2. База панели
Подробно — [DATA.md](DATA.md). Коротко: `posts` (общая лента), `byauthor/<uid>/posts` (посты авторов), `ideas`, `editors`, `roles`, `invites`, `settings`, подколлекции `versions` и `notes` у постов.

| 6749993 | design_radar 2000×640 | Обложка: `topic_id` (`[A-Za-z0-9_-]{1,38}`), `title`, `label`, `art` или `image_base64` → проверка 2000×640, загрузка в Telegram, ответ `photo_file_id` |
| 6841226 | DR util: загрузить фото для поста | `image_base64` + `key` → отправка в служебный чат 26530591, удаление сообщения, ответ `photo_file_id` |
| 6801221 | загрузка фото по URL | `image_url` + `topic_id` → `photo_file_id` (для фото из первоисточников) |
| 6802346 / 6802352 / 6802286 | бот вопросов @designradar_ask_bot | вебхук бота, его служебный API, перенос фото |

## Как пост попадает в канал

1. Черновик пишет задача по расписанию (или автор в панели) → `posts` со статусом `review`.
2. Екатерина правит в панели (автосохранение, история версий, линтер, «Переписать с Claude»).
3. **Опубликовать** → панель собирает `rich_message` (обложка рендерится в браузере и грузится через 6749993, картинки — через 6841226) → 6801242 `sendRichMessage` → номер сообщения сохраняется в посте.
4. **Запланировать** → панель готовит `outbox.body` и ставит задаче «Отложенная публикация» время запуска (`update_trigger`).
5. **Отклонить** → окно «Почему?» → причина сохраняется, задачи учатся; «Напиши заново» создаёт идею с `rewrite_of`.
