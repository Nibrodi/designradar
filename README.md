# Дизайн-Радар

Редакция Telegram-канала [@designradar_lab](https://t.me/designradar_lab): панель согласования постов, рендер обложек, генератор каруселей, задачи Claude по расписанию и вся документация.

Claude — оператор проекта: пишет черновики, рисует обложки, ведёт панель и этот репозиторий. В канал ничего не уходит без кнопки главного редактора.

## Что где

| Папка | Что внутри |
|---|---|
| `panel/src/` | Исходники панели: `app/` (логика по частям 00–99), `render.js` (обложки 2000×640 и шрифт), `styles.css`, `head.html`, `body.html` |
| `panel/test/` | Автопроверка: `check.js` открывает все посты в светлой и тёмной теме и прогоняет основные сценарии на копии базы (`mockreal.js`) |
| `panel/dist/` | Собранная панель, ровно то, что опубликовано |
| `carousel/` | Генератор карусели 1080×1350 (`make_carousel.py`) и пример спецификации |
| `docs/` | Как устроены панель, бот-редактор и самопроверка поста |

## Сборка

```bash
cd panel
npm install          # один раз, ставит playwright
npx playwright install chromium
bash build.sh        # собирает dist/ и гоняет автопроверку
```

Если проверка упала, сборка останавливается: публиковать такую версию нельзя.

## Где живёт панель сейчас

Панель опубликована как артефакт Claude, данные хранятся в его базе. Публикация в канал идёт через сценарии Make, отложенная — через задачи по расписанию в Claude.

## Секреты

Токен бота, ключи API и доступы в репозиторий **не кладём никогда**. Они живут только в Make и в настройках сервисов.

Стандарт канала (ТЗ, журнал ошибок, уроки из правок) ведётся в документе Claude «Регламент Дизайн-Радара».

## Версии

Номер версии панели лежит в `panel/VERSION`, история — в `panel/CHANGELOG.md`. Перед выпуском новой версии:

1. Поднять номер в `VERSION`: мажор — меняются данные или права, минор — новая возможность, патч — исправление.
2. Добавить запись сверху в `CHANGELOG.md`. Без неё сборка не пройдёт.
3. `bash build.sh`, коммит с номером версии в заголовке («Панель X.Y.Z: …»), пуш, публикация `dist/` в артефакт.

Три последних записи журнала панель показывает в окне «Что нового» (кнопка с номером версии в шапке).

## Права доступа в базе

| Путь | Кто читает | Кто пишет |
|---|---|---|
| `posts` (общая лента), `settings` | все, кто открыл панель | только главный редактор |
| `byauthor/<id>/posts` | редакция | автор — только свою папку; главный редактор — все |
| `editors/<id>` (анкеты) | редакция | каждый — только свою |
| `roles/<id>` (публикует сам, пауза, удалён) | редакция | только главный редактор |
| `invites` | редакция | только главный редактор |
| `ideas` | все | редакция |
