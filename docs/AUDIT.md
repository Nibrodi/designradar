- **Доступ по ссылке.** Любой с ссылкой — «участник»: может завести анкету и черновики в своей папке. Посты и права защищены правилами базы, но для чистоты: в меню «Поделиться» панели выдавать доступ по почте и убирать удалённых. *Сделать при первом внешнем авторе.*
- **Кнопки Claude у авторов** работают с их собственных аккаунтов Claude (лимиты их подписки). Без подписки — только ручной текст. *Ок для команды до ~5 человек.*

### Устойчивость
- **Make — единая точка отказа** публикации. Если сценарий 6801242 упадёт, публикация встанет. Защита: статусы `publish_unknown` + сторож + push. Резерв (публикация из задачи напрямую в Bot API) невозможен — в окружении Claude нет доступа к api.telegram.org.
- **Расход Make.** Каждая публикация с обложкой и картинками — 2–6 операций. При 5–6 постах в день это ~1 000 операций в месяц — в пределах тарифа. Следить в недельной проверке, если каналов станет больше.
