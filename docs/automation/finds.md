# Охотник за находками

`CRON_TZ=Europe/Moscow 23 10 * * *` · создано 31.10.2026, обновлено 31.10.2026 (фото по ссылке, без операций Make)

Каждый день: 1 готовый пост «Находка» с фото в «Ревью» + до 3 кандидатов в «Идеи» (со ссылкой «источник ↗»). Екатерина отбирает и планирует; кандидата можно «Отдать Claude» — его напишет «Запас постов».

Источники: новые проекты студий (Лебедев, Бюро Горбунова, Depot, Чулаков, AIC, CreativePeople, Volga Volga, Suеta, Ritm, Brenda, IDEA и др.), локальные бренды с дропами (как 54maggg), adindex.ru/news/design, sostav.ru, workspace.ru, vc.ru/design, skillbox.ru/media/design, bpando.org, packagingoftheworld.com, Brand New, Behance. Instagram/Threads/Pinterest закрыты без входа — находки оттуда присылает Екатерина (ссылкой или скриншотом).

Фото: задача кладёт в пост только ссылки (`cover_url`, `media` с `ext:true`) — операции Make не тратятся. Панель показывает фото в превью; в Telegram они загружаются (Make 6801221) только при «Опубликовать» / «Запланировать». Задача не видит картинки сама — в `check` всегда просьба проверить фото глазами.
