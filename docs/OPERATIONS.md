# Работа с панелью и задачами

## Выпустить новую версию панели
1. Правки только в `panel/src/` (и тесты в `panel/test/`).
2. Поднять номер в `panel/VERSION`: мажор — данные или права, минор — новая возможность, патч — исправление.
3. Запись сверху в `panel/CHANGELOG.md` (`## X.Y.Z — ДД.ММ.ГГГГ` + пункты). Без неё сборка падает.
4. `bash panel/build.sh` → «Все проверки прошли», «BUILD OK vX.Y.Z».
5. Коммит «Панель X.Y.Z: …», пуш.
6. Опубликовать `panel/dist/` в артефакт по той же ссылке (capabilities не передавать — сохраняются; передавать только если меняются).

Если опубликованные файлы не совпадают с последними известными Claude, он сначала читает их и сверяет (diff), чтобы не затереть чужие изменения.

## Автопроверка (`panel/test/check.js`)
Открывает все посты во всех вкладках в светлой и тёмной теме, затем сценарии: карусель, оформление, заметка, планирование, публикация, панель выделения, варианты заголовка, переписывание (2 варианта + «Твой текст»), генерация карусели, приглашение, тестовый вход, права (пост автора, roles, перенос в общую ленту), отказ с причиной, телефон 375 px (без горизонтальной прокрутки, нижняя панель, меню, «Что нового», «+», «Настроить вид», мобильный редактор).

Объекты базы в заглушке заморожены, как в настоящей базе: изменять их нельзя, только копию (`JSON.parse(JSON.stringify(a))`).

## Подводные камни
| Симптом | Причина | Что делать |
|---|---|---|
| «Cannot assign to read only property» | объект из базы заморожен | работать с глубокой копией |
| «Неверный ID статьи» в 6749993 | символы вне `[A-Za-z0-9_-]` в `topic_id` | заменять на `-`, до 38 знаков |
| `null` в интерфейсе | `replaceChildren(..., null)` | фильтровать `.filter(Boolean)`; `h()` сам пропускает null |
| Нижняя панель видна только при прокрутке | приложение Claude сдвигает страницу | «Настроить вид» → «Подъём от нижнего края» |
| Fixed-элемент приклеился не к экрану | `backdrop-filter`/`transform` у предка | не ставить их на шапку с навигацией |
| Литеральные переносы в регулярках | вставка кода через Python без raw-строк | `node --check` (build.sh делает) |
| Рубрика сбрасывалась | её нет в списке select | список расширен, незнакомая добавляется |
| Пуш тегов из сессии Claude — 403 | ограничение прокси | версия в `VERSION`, теги не нужны |
| Обложка: ₽, «…», «→» | нет в шрифте рендера | писать словами, стрелки рисовать |

## Задачи по расписанию
- Инструкции — в [automation/](automation/). При изменении задачи обнови и файл здесь.
- Все задачи читают регламент → правила голоса меняются в одном месте («Уроки из правок Екатерины»).
- Старые задачи «Публикация поста из панели» и «Проверка связи с Telegram» (через `TELEGRAM_BOT_TOKEN` в окружении) **не используются**: в окружении нет ни токена, ни доступа к api.telegram.org. Их можно выключить.

## Секреты
Токен бота — только в Make. В коде, базе, задачах, чате и репозитории его быть не должно. Перед коммитом: `grep -rE "[0-9]{8,10}:AA[A-Za-z0-9_-]{30,}" .` должен ничего не найти.
